# BonkDAO

BonkDAO is an innovative decentralized autonomous organization that aims to discover and promote quality tokens through community voting mechanisms. As a derivative project of LetsBonk, BonkDAO adopts a completely new model that differs from traditional pump and dump schemes.

## Features

- Community-Driven: All decisions are made through community voting
- 24-Hour Cycle: Each voting round lasts 24 hours
- Transparent & Fair: All voting processes and results are recorded on the blockchain
- Decentralized: Operates on smart contracts to ensure fairness

## Tech Stack

- Frontend: Svelte
- Blockchain: Solana
- Smart Contracts: Rust

1. Clone the project
```bash

```

2. Install dependencies
```bash
npm install
```

3. Start development server
```bash
npm run dev
```
